# graphql-forum

[![CI](https://github.com/marcus-beauregard/graphql-forum/actions/workflows/ci.yml/badge.svg)](https://github.com/marcus-beauregard/graphql-forum/actions/workflows/ci.yml) [![License: GPL-2.0-or-later](https://img.shields.io/badge/license-GPL--2.0--or--later-blue.svg)](LICENSE)

A GraphQL forum backend built with Apollo Server. Demonstrates a typed schema,
nested resolvers, and mutations. In-memory store for simplicity.

## Contributing

Humans and automated agents are both welcome. There is no CLA — every commit carries a [DCO](https://developercertificate.org/) sign-off (**git commit -s**). Start with a [good first issue](https://github.com/marcus-beauregard/graphql-forum/issues?q=is%3Aissue+is%3Aopen+label%3A%22good+first+issue%22) or read [CONTRIBUTING.md](CONTRIBUTING.md).
